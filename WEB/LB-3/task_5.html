Основи CSS

Що таке CSS?

CSS (Cascading Style Sheets) - мова стилів для оформлення веб-сторінок. Дозволяє контролювати:

  • Кольори
  • Шрифти
  • Розміри елементів
  • Позиціонування

Основні властивості

Властивість Опис Приклад
color Колір тексту color: #ff0000;
font-size Розмір шрифту font-size: 16px;
margin Зовнішні відступи margin: 20px;
padding Внутрішні відступи padding: 10px;

Переваги CSS

  • Розділення контенту та оформлення
  • Легке оновлення стилів
  • Адаптивний дизайн
  • Анімації та ефекти
